# atagulgames

Atagül Games — küçük oyun projeleri koleksiyonu.

## Proje Hakkında

Bu depo, öğrenme ve deney amaçlı geliştirilmiş küçük oyun projelerini içerir. Her oyun kendi dizininde bulunur ve ilgili talimatlar varsa oyun klasöründe README dosyasıyla birlikte gelir.

## Özellikler

- Farklı dillerde ve teknolojilerde yazılmış örnek oyunlar
- Öğrenme ve referans amaçlı kod
- Katkılara açık yapı

## Kurulum

Gereksinimler projeye göre değişir. Genel kullanım:

1. Depoyu klonlayın:

   git clone https://github.com/ama07a/atagulgames.git
   cd atagulgames

2. Her oyun klasöründeki README veya talimatları okuyun ve ilgili bağımlılıkları yükleyin.

3. Oyunları çalıştırmak için ilgili dizine gidin ve o oyun için belirtilen komutları çalıştırın.

## Katkıda Bulunma

Katkılarınızı memnuniyetle karşılıyoruz. Yeni bir oyun eklemek veya mevcut bir oyunu geliştirmek için:

1. Fork yapın
2. Yeni bir branch açın (örn. `feature/yeni-oyun`)
3. Değişikliklerinizi commit edin
4. Pull request açın

Lütfen kod stiline ve açıklayıcı commit mesajlarına dikkat edin.
